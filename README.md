# Repo to GDrive CLI

Utilitário de linha de comando (CLI) em Python para comprimir o conteúdo de um repositório local e enviá-lo automaticamente para uma pasta específica no Google Drive.

## Objetivo

- Compactar o conteúdo de um repositório/diretório local.
- Realizar o upload do arquivo compactado para uma pasta configurada no Google Drive.
